# Grid Infrastructure Data Analysis

## Overview
Automated data pipeline evaluating national power grid infrastructure, substation asset age profile, capacity risks, and transmission line technical losses.

## Setup & Prerequisites
Install required Python packages:
```bash
pip install pandas matplotlib streamlit plotly
```

## Execution Instructions
**Task 1.2 (EDA):**
```bash
python analysis.py 
```
Generates foundational summary statistics and geographic distribution charts.

**Task 2.3 (Business Intelligence and Reliability)**
```bash
python task2_3_footprint.py
```
Outputs asset age distributions, loss proxy scores, and utility capacity breakdowns.
